01

检索与生成

组织生成、嵌入、重排和向量存储，决定资料如何被检索并生成回答。

①

生成模型（LLM）

▾

负责把检索到的资料组织成回答（RAG 流程的生成环节）。 使用 OpenAI 兼容接口，可连接本机服务或兼容的云端服务。本地示例通常来自 Ollama、vLLM、LM Studio 等兼容服务。

当前版本使用标准 OpenAI Chat Completions 协议。
本地示例：http://127.0.0.1:11434/v1；云端示例：https://api.openai.com/v1。以实际服务根地址为准。
本地服务若不需要鉴权可留空；云端服务通常必须填写。

②

嵌入模型（Embedding）

▾

负责把文档编码成向量（RAG 流程的检索环节）。换模型或维度会让旧向量失效，需要重建知识库。

默认使用本机 Ollama 的 bge-m3:latest。嵌入服务与生成模型相互独立。

尚未测试
③

重排序模型（Rerank）

▾

可选：对检索结果再排序。本地模式使用 Cohere 兼容的 /rerank 服务；云端模式支持 Cohere、Jina 和阿里云 DashScope。

常见模型：BAAI/bge-reranker-v2-m3（本地兼容服务） · jina-reranker-v2-base-multilingual · gte-rerank-v2

尚未测试
④

向量存储（Vector Store）

▾

当前版本使用本地文件向量库，无需 Docker 或外部向量数据库。

Qdrant 或云端向量库当前不可选。启用前需要后端适配、数据迁移/重建方案和独立连接测试；当前服务端也未提供向量库独立测试。

02

数据与入库

组织知识库位置、入库质量门槛、确认流程、文件夹轮询和 OCR。

⑤

存储路径

▾

知识库落地在磁盘上的位置。换电脑或搬家时只需要改这里的路径；数据目录留空表示沿用 LightRAG 自身设置。

⑥

入库质量校验（Quality Gate）

▾

上传的文件先在本地解析为 Markdown 再做质量校验：只有通过校验的内容才会进入知识库。 这道门没有总开关（ QUALITY_ENABLED 已失效）：校验恒定运行，没通过的文件只能在 上传卡片上点「仍要入库」由你自己放行，档案里会留下「人工放行」记录。 留空表示沿用 .env / 内置默认值；选择 standard / strict / loose 时，下面的具体阈值由预设决定（自定义数值会被忽略）。

⑦

入库确认（Ingest Confirm）

▾

质量校验通过不等于直接入库：文件会停在「待确认」，由你点「入库」或「跳过」——中间那一步永远由你决定。
always 每个文件都问你（默认，最稳）；auto 让建议说话——「建议直接入库」的自动放行， 提示「再看一眼 / 谨慎入库」的仍会停下问你；off 通过校验就直接入库（不推荐：错内容也会写进知识库）。
留空表示沿用 .env / 内置默认值；改完需重启服务生效。上传卡片上还有「本次运行内全部允许」的临时开关（重启即失效）。

⑧

文件夹轮询（收件箱自动扫描）

▾

默认关闭。启用后程序每 N 秒扫描指定目录，等文件大小和修改时间稳定后， 复用网页上传的解析与质检流水线，结果只进入本机复核队列，不会自动写入知识库。
源文件始终保留在原处，不移动、不覆盖、不删除；内容完全相同（sha256 一致）的文件只受理一次。 不支持的扩展名、隐藏文件、临时文件、符号链接和超限文件会被跳过或标记失败，源文件同样保留。
目录和开关改完需重启服务生效。 看进度请打开 文件管理 页。

⑨

OCR 文字识别

▾

用于扫描件、图片，以及 Word / PPT / PDF 里的内嵌图片。默认 OCR_MODE=off。
本机 Windows OCR 使用系统自带语言包在本机识别，不外发文件、不需要 API Key； 未安装对应语言包时会明确显示不可用。

manual 模式会停在「需要 OCR」并等待手动操作；auto 模式会在本机自动识别，耗时取决于图片数量和 CPU。

云端 OCR 字段只读保留；当前版本只开放本机 Windows OCR，不发送文件。

A

局域网设备授权

▾

允许同一局域网内的平板或手机通过聊天地址访问。设备请求只在电脑本机确认，设置接口继续保持仅本机可写。

平板直接打开聊天地址；这里出现设备后点一次“允许”，无需输入授权码或设备名。
↗
局域网访问说明

通用格式：http://<电脑局域网IPv4>:18080/web

示例（不是当前地址）：http://192.168.1.100:18080/web

在电脑的网络设置中查看当前 Wi-Fi 或以太网的 IPv4 地址；Windows 也可以运行 ipconfig 查看，把示例中的 IP 换成实际地址。

平板和电脑需要处于同一局域网。

平板打开地址后会自动发送连接请求，请在电脑端局域网授权“等待允许”中确认授权使用。
